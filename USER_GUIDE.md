# Руководство пользователя платформы ИОТ

Платформа формирует индивидуальную траекторию обучения государственного гражданского служащего на основе его профиля, истории обучения и официального каталога Корпоративного университета Санкт-Петербурга. Итог является рекомендацией для проверки сотрудником или методистом, а не автоматическим кадровым решением.

## 1. Вход и учётная запись

Откройте адрес, предоставленный администратором, например `http://localhost:8088/`.

- Для новой учётной записи нажмите «Регистрация», укажите имя, email и пароль длиной 12–128 символов.
- Для существующей учётной записи войдите по email и паролю.
- После завершения работы используйте «Выйти», особенно на общем компьютере.

Новая учётная запись получает роль `Employee`. Доступ к реестру сотрудников и административным операциям выдаёт администратор согласно внутреннему регламенту.

## 2. Создание траектории

Откройте «Конструктор траектории». Возможны два способа ввода.

### Ручной профиль

1. Укажите ФИО, должность и ИОГВ.
2. Обязательно укажите цель развития; стаж и историю обучения заполните при наличии.
3. В выпадающих списках начните печатать, чтобы отфильтровать варианты.
4. Для нескольких сотрудников добавьте профили по одному; в одном запуске допускается до 15 профилей.

Чем конкретнее цель развития, тем проще проверить обоснование рекомендации. Не добавляйте сведения, которые не требуются для обучения.

### Загрузка файлов

Поддерживаются `.json`, `.xlsx`, `.xls`, `.csv` и `.zip`.

- не более 20 файлов за один запрос;
- не более 25 МБ на файл;
- не более 50 МБ суммарно;
- архив должен содержать только поддерживаемые данные и пройти проверку безопасности.

После выбора проверьте имя, размер, расширение и статус каждого файла. Ошибочный файл можно удалить отдельно или очистить весь список. Если система не распознала ни одного профиля, исправьте структуру файла или используйте ручной ввод.

## 3. Выбор модели и запуск

Список показывает только доступные в текущей установке модели:

- `Qwen Local` — обработка внутри сервера организации;
- `DeepSeek` — доступен при настроенном ключе;
- `GigaChat` — доступен при настроенном ключе.

Если модель недоступна, выбрать её нельзя. Сообщите администратору текст ошибки; не повторяйте запуск многократно.

Нажмите «Сформировать индивидуальную траекторию обучения». Задача проходит состояния:

- `В очереди` — запрос сохранён и ожидает обработки;
- `Обработка` — выполняется текущий профиль;
- `Повторная попытка` — временная ошибка модели, система продолжает автоматически;
- `Готово` — проверенная траектория сформирована;
- `Готово с ограничениями` — создан резервный результат, требующий проверки;
- `Ошибка` — обработка не завершена, показана причина.

Страницу можно обновить: задача и прогресс сохраняются на сервере. Пакет обрабатывается последовательно, поэтому локальная Qwen может работать заметное время.

## 4. Проверка результата

В готовой траектории проверьте:

1. сотрудника, должность, ИОГВ и цель;
2. отсутствие уже пройденных программ;
3. соответствие каждого курса заявленной цели;
4. обоснование и источники рекомендации;
5. ограничения данных и способ выбора когорты;
6. этапы и сроки — они показываются только при наличии в проверенном результате.

Карточка курса открывает официальную аннотацию, формат, трудоёмкость, результаты обучения и обоснование. Если исходных уровней компетенций нет, система не рисует фиктивную матрицу. Если подходящей когорты нет или её использование отключено администратором, это отображается явно.

Статус «Готово с ограничениями» означает, что часть модельного конвейера не завершилась. Экспорт такого результата блокируется до экспертной проверки; это не полноценный финальный план.

## 5. Сохранение, экспорт и архив

- Название отчёта можно изменить в его карточке; нажмите «Сохранить название».
- Для проверенного результата доступны PDF, XLSX и JSON.
- Кнопка экспорта показывает процесс, успех или ошибку. Если автоматическое скачивание заблокировано браузером, используйте предложенную ссылку.
- Архивирование скрывает отчёт из активной истории, но не удаляет его.
- В «Настройки → Архив» отчёт можно открыть или восстановить.

Не пересылайте экспорт лицам без права доступа: файл может содержать сведения профиля сотрудника.

## 6. Каталог и аналитика

### Каталог

Раздел содержит 159 программ 2025 года. Поиск работает по названию и содержанию; фильтры ограничивают формат и доступные категории. Пустое поле означает, что в источнике нет подтверждённого значения.

### Аналитика обучения

Раздел строится на 1 314 исторических записях. Выберите должность; при выборе другой должности все показатели и графики пересчитываются. Для сравнения выберите вторую должность. Если данных нет, интерфейс показывает пустое состояние, а не нулевые вымышленные показатели.

## 7. Настройки интерфейса

В настройках доступны системная, светлая и тёмная темы, режим для слабовидящих и минимальный интерфейс. Переключатели применяются сразу и сохраняются для учётной записи. «Сбросить» возвращает значения по умолчанию.

Интерфейс поддерживает клавиатуру: переходите по элементам клавишей `Tab`, активируйте кнопки `Enter` или `Space`, закрывайте диалоги `Escape`.

## 8. Типовые проблемы

| Ситуация | Что сделать |
|---|---|
| Не удаётся войти | Проверьте email, раскладку и длину пароля; затем обратитесь к администратору. |
| Файл отклонён | Проверьте расширение, размер и структуру; загрузите файл без пароля и макросов. |
| Нет доступной модели | Администратор должен восстановить локальную модель или настроить облачный ключ. |
| Задача долго в очереди | Не создавайте дубликат; обновите страницу и проверьте статус позже. |
| Результат «с ограничениями» | Передайте его методисту; экспорт намеренно заблокирован. |
| Не обновилась аналитика | Сбросьте фильтр и выберите должность снова; если проблема повторяется, сообщите выбранные значения и время администратору. |
| Экспорт не скачался | Разрешите загрузки для сайта или используйте резервную ссылку. |

При обращении в поддержку укажите время, экран, действие, текст ошибки и идентификатор задачи. Не отправляйте пароль, JWT-токен или `.env`.
