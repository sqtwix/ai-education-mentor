# Инструкция пользователя: ИИ-Агент индивидуальной траектории обучения (ИОТ)

Добро пожаловать в систему интеллектуального проектирования индивидуальных образовательных траекторий государственных гражданских служащих (ГГС) Санкт-Петербурга.

---

## 1. Назначение системы

Система предназначена для:
- Формирования персонализированной программы обучения на 2025 год с учетом должности, ведомства (ИОГВ) и целей профессионального роста.
- Исключения ранее пройденных программ из рекомендаций.
- Использования статистики истории обучения для подходящей когорты, если такая когорта есть в исходных данных и администратор настроил согласованный минимальный размер.
- Экспорта индивидуального плана обучения в форматы **Excel (.xlsx)**, **PDF** и **JSON** после проверки результата.

---

## 2. Пошаговый сценарий работы

### Шаг 1. Открытие системы
Откройте браузер и перейдите по адресу: **`http://localhost/`** (или адресу, предоставленному администратором).

### Шаг 2. Выбор или создание профиля служащего (Раздел «Конструктор ИОТ»)
Доступны следующие режимы:
1. **Выбрать сотрудника из реестра истории** (только для роли администратора):
   - Выберите профиль из 323 записей, загруженных из предоставленного реестра.
   - Система заполнит должность, ведомство и историю обучения этого профиля.
2. **Создать новый профиль ГГС**:
   - Введите ФИО сотрудника.
   - Выберите должность из выпадающего списка (36 реальных должностей ГГС Санкт-Петербурга).
   - Выберите исполнительный орган государственной власти (ИОГВ).
   - Укажите фактический целевой вектор развития сотрудника.
   - При необходимости добавьте ранее освоенные курсы в блок истории.

### Шаг 3. Выбор группы ИИ-агентов (провайдера нейросети)
Система показывает три группы и разрешает выбрать только настроенный вариант:
- **DeepSeek**: облачная модель и ее идентификатор из конфигурации; требуется ключ DeepSeek API.
- **Sber GigaChat**: облачная модель и ее идентификатор из конфигурации; требуется ключ провайдера.
- **Qwen Local (GGUF)**: локальная модель через `llama.cpp`; сервер должен отвечать на healthcheck.

Если ни одна модель не настроена, запуск блокируется с явным сообщением вместо имитации модельного анализа.

### Шаг 4. Генерация траектории
Нажмите кнопку **«Сформировать индивидуальную траекторию обучения»**.
Система запустит конвейер из 3 агентов:
1. **Аналитик компетенций (`competency-analyst`)**: выделяет подтвержденные входными данными сигналы развития и отфильтровывает пройденные курсы.
2. **Архитектор траектории (`trajectory-architect`)**: отбирает кандидатов из официального каталога; число этапов и сроки не подставляются по умолчанию.
3. **Методолог-обоснователь (`trajectory-justifier`)**: формирует обоснования и указывает ограничения исходных данных; когортная статистика используется только при наличии подходящей группы.

---

## 3. Работа с готовой траекторией

После завершения генерации открывается интерактивный экран траектории:

- **Этапы обучения**: переключайтесь между этапами, если они присутствуют в проверенном результате; fallback содержит единый список кандидатов для экспертной проверки.
- **Интерактивные карточки курсов**:
  - Бейджи типа программы (**ППК** / **ЭК**), длительности (ак. часы) и приоритета.
  - Кликните на карточку любого курса, чтобы открыть модальное окно с официальной аннотацией, целями, результатами ZUV (*«знать, уметь, владеть»*) и обоснованием ИИ.
- **Матрица компетенций (Skill Radar)**: строится только если backend передал подтвержденные уровни; иначе интерфейс показывает ограничение данных.
- **Бенчмарк должность + ИОГВ**: статистика коллег по точной когорте или честное предупреждение, если использован расширенный срез.

---

## 4. Экспорт и сохранение результатов

В верхней панели экрана траектории доступны кнопки скачивания:
- **Excel (.xlsx)**: книга с индивидуальным планом и только теми аналитическими листами, для которых есть данные.
- **PDF**: официальный отчет с таблицами этапов и методическим заключением.
- **JSON**: структурированный файл для интеграции с кадровыми системами и LMS.

---

## 5. Дополнительные разделы

- **Каталог программ 2025 года (`#catalog`)**: полнотекстовый поиск и фильтрация полного каталога программ Корпоративного университета по категориям, часам и компетенциям.
- **Бенчмарк должностей (`#analytics`)**: аналитика востребованности программ среди 36 должностей на основе 1 314 записей обучения.
- **История траекторий (в боковой панели)**: быстрый доступ к ранее сохраненным траекториям сотрудников.
