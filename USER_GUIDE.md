# Инструкция пользователя: ИИ-Агент индивидуальной траектории обучения (ИОТ)

Добро пожаловать в систему интеллектуального проектирования индивидуальных образовательных траекторий государственных гражданских служащих (ГГС) Санкт-Петербурга.

---

## 1. Назначение системы

Система предназначена для:
- Автоматического формирования персонализированной программы обучения на 2025 год с учетом должности, ведомства (ИОГВ) и целей профессионального роста.
- Автоматического исключения ранее пройденных программ (без повторов).
- Подбора курсов на основе реального опыта и успешности коллег аналогичной должности.
- Экспорта официального индивидуального плана обучения в форматы **Excel (.xlsx)**, **PDF** и **JSON**.

---

## 2. Пошаговый сценарий работы

### Шаг 1. Открытие системы
Откройте браузер и перейдите по адресу: **`http://localhost/`** (или адресу, предоставленному администратором).

### Шаг 2. Выбор или создание профиля служащего (Раздел «Конструктор ИОТ»)
Вам доступны два удобных режима:
1. **Выбрать сотрудника из реестра истории**:
   - В выпадающем списке выберите любого из 323 реальных служащих Санкт-Петербурга.
   - Система автоматически загрузит его должность, ведомство и историю всех ранее пройденных курсов.
2. **Создать новый профиль ГГС**:
   - Введите ФИО сотрудника.
   - Выберите должность из выпадающего списка (36 реальных должностей ГГС Санкт-Петербурга).
   - Выберите исполнительный орган государственной власти (ИОГВ).
   - Укажите целевой вектор развития (например: *«Развитие навыков управления проектами, клиентоцентричности и работы с цифровыми данными»*).
   - При необходимости добавьте ранее освоенные курсы в блок истории.

### Шаг 3. Выбор группы ИИ-агентов (провайдера нейросети)
Выберите один из трех доступных вариантов:
- **DeepSeek V3 / R1**: зарубежная модель высокой точности структурирования.
- **Sber GigaChat Pro**: отечественная модель, оптимизированная под терминологию госслужбы РФ.
- **Qwen Local (GGUF)**: 100% автономная локальная модель для работы в закрытом контуре (Air-Gapped).

### Шаг 4. Генерация траектории
Нажмите кнопку **«Сформировать индивидуальную траекторию обучения»**.
Система запустит конвейер из 3 агентов:
1. **Аналитик компетенций (`competency-analyst`)**: анализирует дефицит навыков и отфильтровывает пройденные курсы.
2. **Архитектор траектории (`trajectory-architect`)**: выстраивает логическую последовательность этапов (Базовый → Профильный → Продвинутый).
3. **Методолог-обоснователь (`trajectory-justifier`)**: рассчитывает статистику коллег и формирует доказательное обоснование по каждому курсу.

---

## 3. Работа с готовой траекторией

После завершения генерации открывается интерактивный экран траектории:

- **Этапы обучения**: переключайтесь между этапами или просматривайте весь маршрут целиком.
- **Интерактивные карточки курсов**:
  - Бейджи типа программы (**ППК** / **ЭК**), длительности (ак. часы) и приоритета.
  - Кликните на карточку любого курса, чтобы открыть модальное окно с официальной аннотацией, целями, результатами ZUV (*«знать, уметь, владеть»*) и обоснованием ИИ.
- **Матрица компетенций (Skill Radar)**: лепестковая диаграмма показывает текущий уровень и целевой прирост навыков.
- **Бенчмарк по должности**: процент коллег, успешно прошедших рекомендованные курсы.

---

## 4. Экспорт и сохранение результатов

В верхней панели экрана траектории доступны кнопки скачивания:
- **Excel (.xlsx)**: 3-страничная книга (Лист 1: *Индивидуальный план ИОТ*, Лист 2: *Матрица компетенций*, Лист 3: *Бенчмарк по должности*).
- **PDF**: официальный отчет с таблицами этапов и методическим заключением.
- **JSON**: структурированный файл для интеграции с кадровыми системами и LMS.

---

## 5. Дополнительные разделы

- **Каталог программ 2025 года (`#catalog`)**: полнотекстовый поиск и фильтрация всех 221 программ Корпоративного университета по категориям, часам и компетенциям.
- **Бенчмарк должностей (`#analytics`)**: аналитика востребованности программ среди 36 должностей на основе 1 314 записей обучения.
- **История траекторий (в боковой панели)**: быстрый доступ к ранее сохраненным траекториям сотрудников.
