# План честного сравнения 3 групп моделей ИИ
### Кейс 3: ИИ-агент индивидуальной траектории обучения (ИОТ)

Этот файл фиксирует методику production-сравнения моделей. Численные выводы не должны заполняться без воспроизводимого прогона на утвержденном тестовом наборе.

## Сравниваемые группы

1. **Зарубежные модели**: точная модель DeepSeek из `DEEPSEEK_MODEL`.
2. **Отечественные модели**: точная модель Sber GigaChat из `SBERGPT_MODEL`.
3. **Локальные модели**: точный GGUF-файл из `QWEN_MODEL_FILE` через `llama.cpp`.

## Обязательный тестовый набор

Перед финальным отчетом нужен набор контрольных профилей ГГС с экспертной разметкой:

- профиль сотрудника: должность, ИОГВ, стаж, карьерная цель;
- история обучения с явным статусом прохождения;
- эталонные ограничения: какие курсы нельзя рекомендовать повторно;
- экспертная оценка допустимых и недопустимых рекомендаций;
- минимальный размер когорты для бенчмарка `должность + ИОГВ`.

Без этой разметки допустим только smoke-test технической работоспособности, а не вывод о качестве моделей.

## Метрики

| Метрика | Что проверяет | Источник истины |
|---|---|---|
| 0-repeat rate | Пройденные курсы не попадают в рекомендации | История обучения профиля |
| Catalog validity | Каждый курс существует в полном каталоге | `courses_catalog.json` |
| JSON schema validity | Ответ соответствует контракту API | DTO/Pydantic schema |
| Cohort alignment | Бенчмарк строится по `position + department` | Реестр истории обучения |
| Evidence coverage | У каждого курса есть источник рекомендации или честное ограничение | Поля `evidence_sources`, `limitations` |
| PII safety | Внешним моделям не передаются ФИО и лишние ПДн | Логи/трассировка запросов |
| Latency | Время полного конвейера агентов | Инструментальный лог запуска |

## Правило публикации вывода

Финальный вывод о лучшей модели можно публиковать только если:

- заполнены все `TBD` значения;
- рядом с результатами указаны дата прогона, версии моделей, temperature и commit;
- для Qwen указан точный файл модели и `QWEN_MODEL_SHA256`;
- приложен список ограничений тестового набора.

До этого корректная формулировка: "архитектура поддерживает три группы моделей, но финальное качество требует приемочного сравнения на экспертно размеченном наборе".
