# Сравнительный анализ и бенчмарк 3 групп моделей ИИ
### Кейс 3: «ИИ-агент индивидуальной траектории обучения (ИОТ)»

В соответствии с требованиями технического задания проведено экспериментальное сравнительное тестирование трех групп нейросетевых моделей:
1. **Зарубежные модели**: DeepSeek V3 / R1
2. **Отечественные модели**: Sber GigaChat Pro / SberGPT
3. **Локальные автономные модели (Air-Gapped)**: Qwen 2.5 Instruct (GGUF) via `llama.cpp`

---

## 1. Методология и тестовый набор (Test Set)

Для чистоты эксперимента использовался единый стандартизированный тестовый набор из **20 контрольных профилей ГГС** Санкт-Петербурга, охватывающий различные категории должностей и объемы истории обучения:
- **Руководящий состав** (*Начальники управлений, главные бухгалтеры, заместители глав администраций*);
- **Специалисты среднего звена** (*Главные специалисты, ведущие специалисты, консультанты*);
- **Профильные специалисты** (*Юрисконсульты, ИТ-специалисты, специалисты по закупкам 44-ФЗ*);
- **Сотрудники с нулевой историей обучения** (новые служащие);
- **Сотрудники с насыщенной историей** (от 5 до 12 ранее пройденных курсов).

### Критерии оценки:
1. **Исключение дубликатов (0-repeat rate)**: процент сформированных траекторий, в которых *ни один* ранее пройденный курс не попал в список рекомендаций.
2. **Валидность структуры JSON (JSON Schema Validity)**: строгое соответствие выходного JSON контракту Pydantic схемы (наличие всех этапов, курсов, полей ZUV, радара компетенций).
3. **Релевантность когорте (Cohort Alignment)**: учет специфики должности и ведомства (ИОГВ) на основе бенчмарков коллег.
4. **Скорость генерации (End-to-End Latency)**: общее время выполнения трехэтапного конвейера агентов (`competency-analyst` → `trajectory-architect` → `trajectory-justifier`).
5. **Безопасность и автономность (Data Privacy & Air-Gap)**: возможность функционирования без передачи персональных данных во внешние сети.

## 3. Анализ преимуществ и рекомендации по выбору

### 1. DeepSeek V3 / R1 (Зарубежный контур)
- **Сильные стороны**: Наивысшая скорость обработки запросов, превосходное структурирование сложных иерархических планов, подробнейшие формулировки результатов обучения (ZUV).
- **Область применения**: Массовое экспресс-проектирование траекторий при наличии разрешения на использование публичных API с обязательной псевдонимизацией ПДн.

### 2. Sber GigaChat Pro (Отечественный контур)
- **Сильные стороны**: Полное соответствие требованиям законодательства РФ в области импортозамещения ПО, идеальное понимание специфики государственной службы (ФЗ №79-ФЗ, ФЗ №44-ФЗ, бережливые технологии, клиентоцентричность).
- **Область применения**: Рекомендуемый основной облачный провайдер для органов государственной власти и бюджетных учреждений.

### 3. Qwen 2.5 Local via llama.cpp (Автономный локальный контур)
- **Сильные стороны**: 100% конфиденциальность (ни один байт данных не покидает корпоративный сервер), полная независимость от интернета и внешних API, нулевая стоимость за вызовы.
- **Область применения**: Закрытые контуры государственных органов, работа с конфиденциальными кадровыми резервами и режимными ведомствами.
