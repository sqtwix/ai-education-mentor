# Frontend платформы ИОТ

React 19/Vite-интерфейс для входа, создания индивидуальной траектории, просмотра каталога и аналитики, истории отчётов, настроек доступности и экспорта PDF/XLSX/JSON.

## Разработка

Нужен Node.js 20. При dev server API по умолчанию ожидается на `http://127.0.0.1:5050/api/v1`.

```bash
npm ci
npm run dev
```

Доступные команды:

```bash
npm test       # node:test regression suite
npm run lint   # oxlint
npm run build  # production bundle
npm run preview
```

## Конфигурация

- `VITE_API_URL` — нестандартный base URL API; в production обычно не нужен, nginx проксирует `/api/v1`.
- `VITE_OFFLINE_MODE=false` — обязательное production-значение.

Переменные `VITE_*` встраиваются на этапе build. Изменение environment работающего nginx-контейнера не меняет уже собранный bundle — требуется пересборка frontend.

Offline mode предназначен только для разработки интерфейса:

```bash
VITE_OFFLINE_MODE=true npm run dev
```

Он сохраняет данные в `localStorage`, не запускает backend/AI и не используется для приёмки.

## Инварианты

- Авторизация хранит JWT и очищает сессию при подтверждённом `401`; сетевой сбой не должен разлогинивать пользователя.
- API errors, loading, empty, disabled и success состояния отображаются явно.
- В выпадающих списках доступен ввод для поиска; все используют единый визуальный компонент и ширину своей колонки.
- Аналитика пересчитывается при каждом фактическом изменении выбранной должности, включая повторный цикл выбора.
- Отсутствующие поля отчёта не заменяются моками или hardcoded значениями.
- `CompletedWithLimitations` нельзя экспортировать как финальный результат.
- Экспорт соответствует открытому профилю пакетного отчёта и создаёт PDF, XLSX или JSON.
- Интерфейс работает с клавиатуры и без горизонтального overflow на ширине 390 px.

Архитектура, API-контракты и полный набор проверок описаны в [DEVELOPER_GUIDE.md](../DEVELOPER_GUIDE.md).
